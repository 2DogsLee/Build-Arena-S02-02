### 环境物理特性摘要

以下定性规律直接影响设计决策（精确数值由 agent 通过标定试飞自行实测）：

- 真空燃料跨块馈送失效 → 必须规划 Fuel Line
- 高速大角度翻转受风标力矩锁死 → 减速不得依赖空中翻转
- 引擎差动真空中零力矩 → 真空段姿态靠动量执行器
- 气动舵面转向力矩可忽略 → 大气段转向靠姿态-推力耦合
- 爆炸式分离器有分离冲量 → 分离前后差分标定
- 细长堆叠风标扰动可远超轮控权限 → 姿态权限结构级保证
- 地形起伏可达数十单位 → 着陆判据勿依赖固定高度

### 设计方法论

**建造前四大预算**（任一不合格则重新设计）：
1. 质量/推重比：T/W ≥ 1.5
2. 燃耗：各相时间 × 燃烧率 + 20% 余量
3. 控制权限：机动需求 ≤ 执行器能力
4. 结构与供油：Fuel Line / 基座宽度 / 重心高度

**着陆静态稳定性**（建造前预验算）：
- 倾覆角 θ_tip = arctan(d_base / h_CG)
- 稳定条件：预期扰动角 < θ_tip
- θ_tip < 10° 的设计需要修改

**探针阶梯**（建造后逐级验证）：
```
质量探针 → 静态点火 → 悬停探针 → 短距爬升 → 全任务
```

### 迭代纪律

1. 单变量原则：每轮只验证一个改动
2. 离线门：上机前先过离线仿真预测
3. 已知好配置锚点：连续劣化即回滚
4. 假设驱动记录：改动/预期/实测/归因
5. 确认批：闸门全绿后同配置 ≥5 次，取最优
6. 自我复盘：每 5-10 轮或遇瓶颈时，重读知识文件+审视架构

## 最终方案细节

### 机器设计

- **上升段**：两段式（低轨停泊 + Hohmann 抬升），vis-viva 闭环节流
- **着陆系统**：16 段 L 形木质着陆腿（脚点半径 4.0）+ Grip Pad 防滑 + 宽基座低重心
- **姿态执行器**：8× Reaction Steering Block + 12× Steering Thruster (RCS)
- **跨油箱供油**：Fuel Line 网络
- **分离**：Decoupler (ExplodeKey)

### 控制器架构（多相状态机）

```
pad → loft → boost → gravity_turn → insertion_check
  → orbit_raise(Hohmann) → separation
  → payload_coast(被动监视)
  → retro_window(闭式落点预报)
  → kill_burn(两段式) → final_descent(分段PI)
  → touchdown → endpoint_hold
```

- **姿态**：四元数误差 + PD，对准死区门控
- **油门**：矢量分配（侧向修正参与幅值）
- **落点预报**：标定阻力弹道数值积分，每帧重解算
- **横向修正**：PD 律 + 油门矢量分配
- **触地**：静止判据 + 触地速度门 + 末段 PI 收敛

### 闸门验证

每轮 run 结束后从 trajectory.csv 实测 G1-G5（不依赖控制器 self-report）。

## 关键工程洞察

以下为多轮迭代中通过数据分析发现的非直觉结论——每一项都曾导致方向性修正：

1. **双通道控制**：油门管垂直支撑 + 姿态管水平加速——解决垂直推力柱逃逸
2. **角动量守恒**：弹道下坠段 vt 回升——落点预报必须含 L 守恒
3. **有效占空比崩塌**：对准门控过紧会让推力长期被抑制
4. **分离冲量**：爆炸式分离器给载荷冲量，拉低近地点——差分标定+补偿
5. **阻力模型不可辨识**：单指数模型在不同数据段拟合出矛盾参数——分箱非参数拟合
6. **重力损失**：刹车期间重力持续加速——初始速度越高/刹车越慢→重力损失越大
